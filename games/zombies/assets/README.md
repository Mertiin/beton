# Zombies assets

- `zombie-walk.png` — **8×5** top-down walk sheet (64×64 cells). Each row is a skin of the same Riley Gombart CC0 [Animated Top Down Zombie](https://opengameart.org/content/animated-top-down-zombie) move cycle (olive, teal, crimson, ashen, dusty). Art faces +X; the game rotates each zombie toward the cursor and picks a random row on spawn.
