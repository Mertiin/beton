beton

Sample games. They need WebGPU (Chrome or Edge).

  • flappy — click the canvas, then Space flaps.
  • 2048 — arrows or WASD. R restarts.
  • physics — Space drops a box. Arrows or A/D kick it. R resets.
  • netplay — Pong client. C asks for ip:port (H cannot host in the browser).

Click the canvas so the page has keyboard focus. Escape does not quit in the browser. Netplay needs a desktop host; Pages is https so only localhost WebSocket works from this page.
